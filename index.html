ダウンロード後の使い方・無料試用について

Getting started & free trial

Video Bookmark v4.15 / Light v3.13 のWindows向けダウンロードです。購入前に無料でお試しいただけます。

Download Video Bookmark v4.15 or Light v3.13 for Windows. Try the software free before purchasing.

1. ZIPを展開して起動

1. Extract and launch

通常版またはLight版の「無料で試す」を押すと、ZIPをダウンロードできます。保存したZIPを右クリックして「すべて展開」を選び、中のexeを起動してください。詳しい使い方は同梱の説明書をご覧ください。

Select “Try free” for the regular or Light edition to download its ZIP. Right-click the downloaded ZIP, choose “Extract All”, then launch the EXE inside. See the included guide for detailed instructions.

2. 必要なソフトを準備

2. Install the required software

  • 通常版：VLC media player 64-bit
  • Light版：MPC-BE 64-bit ＋ FFmpeg
  • Regular edition: VLC media player 64-bit
  • Light edition: MPC-BE 64-bit + FFmpeg

これらのソフトは配布ZIPに含まれていません。別途インストールしてください。

These applications are not bundled in the ZIP. Please install them separately.

3. 無料で試して、気に入ったらライセンス登録

3. Try free, then activate a license

通常版・Light版とも、新しいしおりを5件まで無料で作成できます。制限を解除するには、該当製品の「購入」ボタンからライセンスをご購入ください。購入後は同じアプリにライセンスキーを登録して利用できます。

Both editions let you create up to five new bookmarks free. To remove the trial limit, purchase a license using the corresponding product’s Buy button. Enter the license key in the same application to activate it.

Bookmark Catalogについて

About Bookmark Catalog

Catalogは、通常版の「しおり目次」から利用する別売りの追加機能です。無料で5回まで起動できます。専用のダウンロードは不要です。通常版Video Bookmarkが別途必要で、Light版には対応していません。

Catalog is a separately sold add-on opened from the regular Video Bookmark application. You can try it for five launches. No separate download is required. It requires the regular Video Bookmark, sold separately, and is not compatible with Light.

購入したCatalogのキーは、目次側の「ライセンス」から登録してください。

Register your Catalog key in the Catalog window’s License dialog.
